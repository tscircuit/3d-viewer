# Fidget-counter GLB fixture

Actual `rushabhcodes/fidget-counter@1.0.12` assembly regenerated from its published
Circuit JSON and 27 downloaded OBJ models with the metadata-enabled
`circuit-json-to-gltf` exporter (commit `e8144a3`, PR #261). All 38 CAD components
carry names and IDs in `node.extras.tscircuit`, enabling hover labels and hiding.

The Fidget Counter story serves the generated bytes directly from the Storybook
deployment at `/prerendered-glb/fidget-counter.glb`. Viewing the story does not
rebuild the circuit or download individual component models.

Generated with `convertCircuitJsonToGltf(circuitJson, { format: "glb",
projectBaseUrl })`, using a local file server for the downloaded models and the
exporter's default board textures. No metadata was inferred from mesh order.

The previous fixture was the original published 7,365,672-byte GLB, downloaded
from https://api.tscircuit.com/package_files/download?package_file_id=3ea38a93-dd1f-4c8c-b0b2-4cfda3050f47.
It lacked component identity extras and has been replaced so this demo exercises
hover interactions on the actual assembly.
